    How the price is earned

    The curve is fitted to the snapshot’s own traded tokens — — — not typed in by hand. Every factor comes from the protocol’s own record: its TVL, its seven-day growth, how long it has run with no token, and how many chains it runs on. No protocol’s name ever changes its score. Each row carries the band the backtest earns: the full model’s leave-one-out median miss, so a value of $10M reads as roughly $3M–$36M instead of a false precision.

    Farm economics, stated

      Growth, maturity, chains

      • Growth: 7-day change clamped to −60%…+120%, half weight — fitted as an effect first, and it missed worse, so it stays an adjustment, validated as part of the full model.
      • Maturity: 0.60 at listing, rising to 1.00 after 3 years with no token — fitted as an effect first, and it missed worse.
      • Chains: +2% per extra chain, capped at +10% — fitted as an effect first, and it missed worse.

      Read this before farming

      “Pre-token” means the protocol’s record carries no token — no market cap, no CoinGecko id, no symbol — not that it has promised one. Implied value is a ranking model fitted to traded tokens, not a price prediction: it says which launch would be biggest if it happened, not that it will happen or what a token would trade at. The farm net is a scenario — 10% of the implied value shared pro-rata by TVL among depositors, on a $1,000 position — not a promise of any payout. Airdrops are never guaranteed, claims never ask you to pay, and the farm plans above are starting points, not advice. Verify every link on the protocol’s own site before you connect a wallet.
